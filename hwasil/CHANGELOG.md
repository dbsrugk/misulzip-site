# 도토리 미술관(옛 작은 화실) 변경 기록

## 수동: 중앙 홀 시작 + 화실(아틀리에) 분리, 자료 연결, 서버 004
- 시작은 중앙 홀(옛 로비, 이젤 없음). 북쪽 큰 문 = 미술관(대회랑), 남쪽 문 = 친구들 신진 작가관, 동쪽 문 밖 오른쪽 = **화실**(지붕 없는 나무 오두막, 이젤 1~6번을 옮김. 번호는 그대로, `ATELIER`, 장소 이동 맨 끝 '화실', 영역 이름 '화실'). 로툰다 분수 위 도토리는 뺌.
- 자료 연결: 명화 23점 사진(`art/`, 모나리자 포함, 미인도만 아직 없음), 대회랑 바닥·카펫·로툰다 바닥 질감(`textures/`), 3D 모델 5곳(`models/*.glb`, 가까이 갈 때만 불러옴, `vendor/GLTFLoader.js`), 효과음 3종(`sounds/`: 발소리·분수·홀 공기), 출처 `CREDITS.csv`. 금색 액자·마스코트·로고·og 이미지는 아직 연결 안 함(도토리 이름을 다시 정한 뒤). 소리 크기는 직접 들어 보고 조절 필요.
- 서버 마이그레이션 004 적용(방문 기록 `hwasil_ping`, 관리자 보관함, 재등록 차단). 설정 > 관리자 > '내린 작품 보관함'. 아침 보고 예약 작업 `dotori-morning-report`(매일 8시경).

## 수동: 박물관 개편 (대회랑·로툰다·NPC·시대 분위기·장소 이름)
- 로비 정면 큰 문 → 중앙 로툰다(분수) → 대회랑 192(명화 24점 자리, 도슨트 카드, 구역별 바닥·카펫·조명·음악). 도슨트·관람객 NPC. 장소 이름 배너. 입장 탭에서 소리 바로 시작. 날씨 기본 맑음(비 제거). 이름 '도토리 미술관'. 입장 화면 짧게.
