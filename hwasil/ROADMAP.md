## 1. 맵이 넓어질 때 꼭 필요한 것 (우선순위)
1. **구역(zone) 시스템**: 구역마다 {경계, 걸을 수 있는지, 지형높이, 켜고 끌 장식} 을 한 곳에 등록. walkable/gY/미니맵이 전부 이 표를 읽게 → 벽 버그 사라지고 새 구역 추가가 쉬워짐.
2. **거리·구역 기반 컬링**: 플레이어 근처 구역의 업데이트만 실행(숲, 나비, 안개, 등불 등). 폰 프레임 방어의 핵심.
3. **품질 단계(저/중/고)**: 설정에서 선택 + 자동 감지(프레임이 낮으면 한 단계 낮춤). 반딧불·불꽃·나비·그림자 개수를 한꺼번에 조절.
4. **로딩 쪼개기**: 처음엔 갤러리·들판만, 산·바다는 가까이 가거나 백그라운드에서 지연 생성 → 첫 접속이 빨라짐.
5. **미니맵 확대/전체 지도**: 구역이 많아지면 길찾기 필수. 구역 이동 버튼에 새 구역 자동 등록.
6. **멀티 접속 부하**: 20명 기준 점검(아바타 갱신 빈도, 원격 보트/다이버).
