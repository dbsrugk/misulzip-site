# 명화관 카테고리 재편 계획

## 지금의 문제
- 명화 44점이 한 줄짜리 대회랑에 11개 구역(구역당 4점)으로 이어져 있습니다.
- 작품을 더 넣으면 복도가 계속 길어져서 끝까지 걸어가기 어렵고, 3D 구조물도 한꺼번에 불러와 느려집니다.
- 구역 이름이 시대(르네상스)와 지역(동양)이 섞여 있어, 원하는 그림이 어디 있는지 찾기 어렵습니다.

## 목표
1. 작품이 100점 넘게 늘어도 걷는 거리가 늘지 않습니다.
2. 찾는 방법이 두 가지입니다: 걸어서 구경하기, 목록에서 골라 바로 가기.
3. 이미 걸린 친구들 그림(슬롯 "방:좌표")은 하나도 깨지지 않습니다.

## 구조: 중앙 로비 + 주제관(부채꼴)
```
            [동양관]
   [풍경관]          [인물관]
        ( 명화 로비 )
   [인상주의관]      [거장관]
            [근현대관]
```
- 명화 로비: 둥근 홀 하나. 문마다 관 이름과 대표작 1점 미리보기.
- 주제관 6개(처음 안): 한 관에 12~16점, 복도 한 줄 길이, 벽 색은 지금 구역별 색을 이어 씁니다.
  | 관 | 들어갈 작품 (지금 목록 기준) |
  |---|---|
  | 거장관 | 르네상스·바로크: 다 빈치, 미켈란젤로, 페르메이르, 렘브란트, 카라바조, 라파엘로 등 |
  | 인상주의관 | 모네, 르누아르, 쇠라, 마네, 세잔 |
  | 근현대관 | 고흐, 고갱, 뭉크, 클림트, 루소 (이후 피카소·칸딘스키·몬드리안·달리) |
  | 동양관 | 한국(김홍도, 신윤복, 정선, 안견), 일본(호쿠사이) (이후 중국 산수) |
  | 풍경관 | 터너, 프리드리히, 모네 풍경, 정선 산수 (주제로 모은 관) |
  | 인물관 | 초상화·인물: 모나리자, 진주 귀걸이 소녀 등 (주제로 모은 관) |
- 같은 작품이 두 관에 걸릴 수 있습니다(시대관 + 주제관). 데이터에 `halls: ['impress','landscape']`처럼 목록으로 둡니다.
- 관은 들어갈 때만 3D를 만들고 나올 때 정리합니다(지연 생성). 작품 사진도 가까운 것부터 불러옵니다.

## 단계 (위험이 작은 것부터)
1. **데이터 먼저** (배포해도 눈에 안 보임): `catalog.js`에 `halls`, `theme`, `era` 필드를 달고, 관 정의 목록(`MUSEUM_HALLS`)을 만듭니다. 지금 복도는 그대로 둡니다.
2. **명화 목록 시트** (바로 체감됨): 명예의 전당처럼 탭(전체 / 관별 / 주제별)과 검색, 작품마다 「보러 가기」 버튼. 걷기 코드(`goPlace`)를 그대로 씁니다. 이것만으로도 복도가 길어지는 불편이 사라집니다.
3. **물리 구조 교체**: 로비와 주제관으로 복도를 다시 배치. 걸린 그림 슬롯 키는 옛 키와 새 키를 둘 다 읽는 이음 코드로 보존합니다.
4. **작품 늘리기**: 관마다 12~16점이 되도록 위키미디어 공용(저작권 풀린 작품)에서 보충. 작품마다 출처와 라이선스를 확인하고 기록합니다.
5. **시험**: 관 이동, 목록 이동, 걸린 그림 유지, 초기 로딩 호출 수(지금 중앙홀 약 744회 이하)를 시험에 추가합니다.

## 참고한 비슷한 가상 전시 (웹 검색)
- [VMVA 가상 미술관](https://nodal.gg/game/vmva-virtual-museum-for-virtual-art-2236930): 주요 방 5개를 흰 벽 전시장 형식으로 나눔. 방 단위로 나누는 구성의 참고.
- [포르보 가상 미술관](https://www.porvoonmuseo.fi/?p=9406): 브라우저에서 도는 사실적인 3D 갤러리. 작품이 많아지면 오래된 기기에서 느려진다고 스스로 안내 → 우리가 지연 생성을 하는 이유.
- 파묘 전시회(pamyo-museum.pages.dev): 재방문 장치(포인트·명예의 전당)가 강점. 우리는 창작·열린 공간이 강점.

## 정해야 할 것
- 관 이름과 개수(위는 처음 안). 시대 위주로 갈지 주제 위주로 갈지.
- 3단계(물리 구조 교체)는 걸린 그림에 영향이 있으니, 배포 전에 한 번 확인받고 싶습니다.
